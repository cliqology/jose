## Notes

**Consider aggregator (a16z, Battery Ventures, Bessemer, Contrary, Greylock, Kleiner
Perkins, Lightspeed, NEA, Sequoia).** Manual review of the raw HTML each of these boards
serves shows a "Powered by Consider" footer attribution linking to
`product.consider.com/ctc/talent-circle` and `consider.com/legal/*`. This is the same kind
of portfolio-jobs aggregator as Getro. `consider.com` has been added to
`AGGREGATOR_SIGNATURES` in `platform_detection.py` alongside the existing `getro.com`
entry, so these nine sources now auto-classify as `unsupported/consider` on every run
instead of needing manual research each time. No adapter exists for Consider yet — same
open "pick a target platform" decision as Getro (see the Issue 06 scoping work).

**YCombinator (workatastartup.com).** Genuinely uncertain, not a detector gap. The page is
served from `bookface-static.ycombinator.com/vite/assets/inertia-waas-*.js` — YC's own
in-house "Work at a Startup" tool, part of their internal Bookface platform, not a
third-party ATS. No JSON-LD job postings appear in the static HTML. Would need a bespoke
collector if this source is ever prioritized.

**Index Ventures.** Also genuinely uncertain. Listings are rendered client-side by
`indexventures.com/static/js/startupjobs.bundle.*.js` (a Vue app on their own domain), not
a third-party ATS. The one JSON-LD block present on the page is SEO schema
(`CollectionPage`/`BreadcrumbList`), not `JobPosting`. Would need a bespoke collector or an
API reverse-engineering effort if this source is ever prioritized.

**Unrelated fix found along the way:** the collector's HTTP client was missing a standard
`Accept` header, which caused `workatastartup.com` to unconditionally return `406` for
every request regardless of retry. Confirmed this isn't a robots/bot-detection restriction
(`workatastartup.com/robots.txt` is fully permissive, and an identical request with a
standard `Accept` header returns `200` under our own honest `User-Agent`). Fixed in
`collectors/http.py` without changing our `User-Agent` identity — this is what let the
retried YCombinator probe succeed (as `uncertain` rather than `error`).
